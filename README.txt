NO PARTICULAR ORDER — WEBSITE KIT
=================================

A responsive visual-miscellany website built from the 10 images supplied in the chat.

FILES
-----
index.html       Main page structure and all content.
styles.css       Layout, responsive styling, animations and visual treatment.
script.js        Gallery filters, search, shuffle and image lightbox.
assets/images/   All 10 supplied images, copied into the project.

HOW TO USE
----------
1. Extract the ZIP file.
2. Open index.html in a modern browser to preview the website.
3. To publish it, upload the extracted folder contents to a static host such as GitHub Pages, Netlify or Vercel.
4. Keep the assets folder beside index.html, styles.css and script.js. The relative image paths depend on that structure.

NOTES
-----
- No build step or package installation is required.
- The site works without a backend.
- Google Fonts are used when a network connection is available; system font fallbacks are included.
- The gallery can be filtered by category, searched, shuffled, and opened in a keyboard-navigable lightbox.
